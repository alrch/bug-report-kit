# Проверка захвата чертежей Греты

Проверка выполнена через CUA в in-app Chromium на настоящем интерфейсе Греты,
1280×720, DPR 2. Локальная demo-kitchen использовала изолированный backend:
production проекты не изменялись. Локальный Kit использовал отдельную SQLite.

Воспроизведены: ошибка CSS Color 4, пустая остановленная WebGL-сцена короба,
закрытие редактора по Escape во время выделения, слишком мелкое превью.
После исправления проверены общий 3D-вид, план, короб с ручками выбора,
технический вид спереди, раскрой после внутренней прокрутки и вращающийся
предпросмотр своего модуля. В двух кадрах выделения модуль неподвижен,
проверенная область совпала побайтно. SVG fixture сохраняет foreignObject
с полем 3600, повёрнутую подпись и современные цвета; WebGL pixel =
[51,153,204,255], render выполнен непосредственно перед чтением.

В форме отчёта проверены Backspace/Delete/Ctrl+Z с выбранным окном;
после отмены оба проёма и выбор окна сохранились. Escape отменяет выделение,
не закрывая редактор короба; Escape из большого просмотра возвращает
заполненную форму. Масштаб 1:1 и вписывание работают. Escape из входа
закрывает вход. После destroy во время выделения обычная клавиатура работает.
Снимок локального отправленного отчёта совпал с preview JPEG по SHA-256.

Средняя абсолютная ошибка RGB (0–255) в областях сравнения native/selection:
общая 3D .0084; план .7396; технический вид 1.5238; короб 1.3066;
раскрой 3.3347. Это сравнение устойчивых кадров, не видеозапись всех
промежуточных кадров и не проверка всех браузеров/масштабов.

Артефакты остаются локально в capture-qa-2026-10-23 рядом с рабочей папкой
чата; в Git не загружаются пользовательские чертежи или секреты.
Серверные tests: 9/9; build и синтаксис browser regression проверены.
Новый capture-drawing.browser.mjs добавлен в общий browser suite, но сам suite
в этой сессии не запускался: UI-проверки выполнялись через CUA.
