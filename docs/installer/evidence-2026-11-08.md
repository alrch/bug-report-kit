# Общий установщик и несколько проектных панелей

Основа — Kit `f358a5d768abbea0eb7ea381268c854727fefd76` и ранее подготовленный
общий установщик от 02.11; изменения применены в отдельной копии. Установщик,
его паспорт, руководство и справка относятся к серверному Docker lifecycle;
изменения `panelGateways` расширяют только разметку панелей и её конфигурацию,
а не право на данные. Дополнительное описание границы — [панели](../panel-gateways.md).

Проверки локального кандидата: 52 теста Kit, 11 bootstrap, 17 направленных
проверок установщика, браузерные сценарии прежней панели и двух разных проектных
панелей, тесты совместимости и отказа перекрывающихся маршрутов. Настоящий
локальный Docker lifecycle с официальным Kit v0.4.6 проверил установку,
обновление, восстановление и откат на временных данных. Тот же lifecycle прошёл
на локальном образе с несколькими панелями `sha256:32c48006…`; после сборки
дополнена проверка зацикливания маршрутов, она проверена отдельно в исходниках.
Более ранние запуски без полученного результата не считаются подтверждёнными.
Это не проверка боевого Kit, выпуска или миграции реальных баз.

Существующий server release workflow дополнен Python bootstrap и браузерной
проверкой двух панелей; результат будущего CI на фактической ревизии остаётся
отдельным фактом. Последующие изменения опубликованного артефакта и его runtime
не считаются подтверждёнными по локальному тестовому образу.
