## Adoption prerequisite found on the real Roof host

The root's separately authorized read-only check failed at its `node` phase;
a bounded follow-up confirmed `nodeAvailable:false` on that Linux host. A
per-project requirement to install Node would leave the common workflow incomplete.
The shared stdlib Python entry `scripts/deploy.py` now resolves an available
Node>=24 or extracts only the public Node binary from the already accepted local
native Linux Kit image. It never starts that helper container or mounts the
application's config/data, installs packages, downloads a runtime, or copies host
libraries. Exact owned stopped-container/image/label checks run before copying and
cleanup. Cache lifetime is private to the invocation/read-only helper.

Before any file write, the tar stream must describe one regular `node` file at
most 256 MiB and free space must exceed its size by 64 MiB. Symlinks, another
entry/path, foreign architecture/identity, unsupported ELF/host libraries and
foreign/old cache directories are rejected. The private ELF64 binary is hashed,
version checked and hash checked before handoff. Its hash binds the extracted
copy, not independent vendor provenance. Loader/preload variables are removed
through the shared `runtime_environment()` API, also used by the owning helper's
direct Node commands.
