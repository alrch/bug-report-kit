# Продуктовое руководство: общий серверный установщик Kit

## Польза и участники

Установщик помогает оператору заменить серверную версию Bug Report Kit и
сохранить собранные баги и доступы команды. Владелец выбирает выпуск и разрешает
поставку. Оператор передаёт параметры существующего экземпляра. Приложение
предоставляет адаптер, защищающий общие службы и прокси. Тестировщики продолжают
пользоваться привычными кнопкой баг-репорта и панелью.

Результат готов, когда работает выбранный образ и проверены внутренняя готовность
и настроенный внешний адрес. Первая версия предназначена для текстового Kit
в Docker: проверенный образ и подготовленное хранилище уже должны существовать.
Получение выпуска, реквизиты, голос, macOS и обработка карточек — отдельные задачи.
На сервере достаточно Python 3 и Docker: если подходящего Node нет, общий
исполнитель временно использует публичный runtime из уже проверенного образа,
без системной установки и изменения работающей службы. Точные границы
подготовки описаны в [INS-01](PASSPORT.md#ins-01).

## Один путь оператора: от обновления к исправлению

Ниже вымышленный учебный пример, а не отчёт о рабочей поставке. Маша сопровождает
текстовый экземпляр Kit проектной команды. Владелец согласовал новый образ;
у Маши есть текущие config, хранилище, параметры установки и одобренный launcher
проекта. Она запускает план: видит, отличается ли образ и требуется ли завершить
прежнее восстановление. Ошибки подготовки останавливают работу до переключения;
сам план ничего не резервирует и не меняет.

Если экземпляр ещё не зарегистрирован в установщике, Маша сначала выполняет
установку: создаёт отдельную службу либо регистрирует доказанно принадлежащую
проекту прежнюю. Здоровая служба с нужным образом используется без пересоздания.
Дальше Маша обновляет её через общий сценарий. Исполнитель сохраняет приватный
backup, проверяет кандидата на копии, затем фактическую предыдущую версию на той
же копии. Прежние записи и файлы должны сохраниться после обеих версий.
Backup остаётся, временная копия удаляется. Маша не подменяет её пустой БД ради
успешного запуска. Эти связи описаны в [INS-02](PASSPORT.md#ins-02).

Предположим, копия прошла проверки, но после переключения перестал отвечать
внешний адрес. Исполнитель возвращает предыдущий runtime и сообщает о неуспешном
обновлении с подтверждённым восстановлением. Маша получает прежнюю работающую
службу, разбирает проблему прокси с командой и исправляет причину. Кандидат пока
не считается доставленным. После исправления она повторяет план и обновление.
Успех подтверждает новую работающую версию; повтор того же обновления проверяет
и использует её без очередного пересоздания.

Теперь тестировщики добавили новые отчёты. Позже владелец попросил вернуть
прежний runtime. Установщик проверяет его на свежей копии сегодняшних данных и
меняет код: новые отчёты и доступы остаются, старый backup их не затирает.
Маша проверяет результат. Если процесс прервался посередине, recover использует
журнал и исходную защитную границу, а не объявляет нынешнее состояние соседей
правильным. Терминальные состояния определяет [INS-03](PASSPORT.md#ins-03).

## Правила и последствия изменений

Код заменяем, отчёты, вложения и доступы — постоянные данные проекта. Поэтому
откат кода не означает откат информации. Прежний runtime должен понимать
результат работы кандидата; одной целостности SQLite недостаточно. Нынешняя
консервативная проверка отвергает изменение прежних строк и файлов. Намеренное
преобразование данных потребует отдельной проверенной политики миграции; даже
удаление истёкшей временной записи может остановить пробу.

Config — общий вход всех этапов. Изменение его байтов после регистрации
останавливает следующие операции: перепривязка пока не реализована. Смену PIN
или токена нельзя спрятать в обновление образа. Совпадение имени контейнера
не доказывает владение: адаптер проверяет службу, mounts и соседей. Общий замок
поставки приложения удерживает эти исходные условия на время операции.

Backup — приватный материал восстановления, а не автоматический исторический
откат, offsite-копия или доказательство проверки восстановления. Незавершённое
восстановление остаётся видимым; первая установка без прежней версии может
потребовать оператора. Status показывает ход работы, verify проверяет службу.

## Текущее состояние и основания

Исходники предоставляют общий CLI планирования, регистрации/установки,
обновления, просмотра состояния, проверки, восстановления и отката на одну
предыдущую версию. Используется прежний runtime Kit. [Свидетельство](evidence-2026-11-02.md)
отдельно фиксирует исполненные локальные проверки, интеграцию Roof и границу
поставки. Документы сами по себе не подтверждают рабочий deploy или человеческую
приёмку исправления. Виджет, панель, API и обработка багов имеют прежние документы;
этот паспорт подробно описывает только установщик.

## Развитие: запуск на macOS

Полезное следующее дополнение позволило бы Маше применять те же правила
сохранения данных и готовности к личному экземпляру на macOS. Сейчас для него
есть отдельные нативные сервисные команды и эксплуатационный порядок.
Минимальное дополнение сохраняет смысл plan/receipt/recover, а создание,
запуск, остановку и проверку принадлежности нативной службы отдаёт проверенному
адаптеру. Точка расширения — существующий нативный runtime, без второго watchdog.

Общими остаются экземпляр, проверенный выпуск, config и данные. Docker image ID
и volume-пробу нельзя просто переименовать: нужны проверяемый каталог выпуска,
online backup, последовательная проба нового и прежнего кода на одной копии,
защита других локальных экземпляров, владение LaunchAgent и поведение после
входа в систему. Прежние Docker-квитанции должны отвергать новый профиль,
а не молча становиться нативными.

Польза — меньше ручного восстановления после входа или перезагрузки и понятный
итог операции. Приёмка потребует изолированной чистой установки, запуска после
входа, повторов без дубликатов, сбоя обновления с сохранением текущих данных
и отказа в захвате чужой службы. Голос и управление несколькими хостами разумно
оставить отдельными этапами. Это предложение, не возможность нынешней версии.
