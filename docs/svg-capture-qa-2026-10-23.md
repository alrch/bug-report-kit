# SVG CSS-рамка: исправление и проверка

html2canvas рисовал CSS-box SVG и затем ещё раз включал его border/padding/margin
в сериализованную SVG-картинку. При отрисовке картинки в content box появлялась
вложенная рамка и смещался рисунок. Сериализуется отдельная копия SVG с размерами
content box; CSS-оформление остаётся внешнему renderer. SVG-геометрия и stroke
внутренних фигур не удаляются. Живой DOM не меняется.

Через CUA на одном fixture при DPR2: исходная882d7f5 дала passed=false,3сегмента
пурпурной рамки вместо2; исправление дало passed=true,2сегмента у content-box и
border-box, liveDomUnchanged=true. Фигуры и подписи визуально сохранены.
Новый tests/capture-svg.browser.mjs покрывает оба box-sizing при DPR1/2; файл
проверен синтаксически, автоматический browser suite в этой сессии не запускался.
Реальное исполнение регрессионного сценария — CUA при DPR2.

Серверные tests9/9; npm build проходит с обязательной проверкой ожидаемого
фрагмента html2canvas. Ошибка при дрейфе зависимости сохраняется для ESM/CJS.
Результаты реальных экранов и поставки находятся в work/tz/2026-10-23-bug-kit-rollout.md
проектов СИЗ и Кровли; этот файл не объявляет их приёмку по локальному fixture.
