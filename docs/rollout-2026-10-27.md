голосовая запись и серверная расшифровка остаются опцией, включённой только

бинарная модель не добавляется в Git и не скачивается клиентскому браузеру.

Runtime из официального архива может отображаться другим локальным image ID
в Docker29/containerd. При этом одного совпадения rootfs недостаточно:
проверяются tar/manifest hashes, linux/amd64 и точный config JSON SHA256 после
экспорта загруженного image. Это включает rootfs/history и весь runtime config;
официальный manifest не переписывается под локальный ID. OCI revision label
может отсутствовать; это не отменяет точную проверку config digest. Присутствующая
неверная метка отклоняется. Фактический image ID
контейнера и verified mapping фиксируются в собственной квитанции потребителя.

## Данные и откат

Перед заменой — online SQLite backup/reopen, private config before-image,
изолированный rehearsal и прежний image/config. Откат возвращает программу и
конфигурацию; старую SQLite нельзя писать поверх новых отчётов. Synthetic
checks не создают реальные баги и не меняют их тексты/вложения/статусы.

Тяжёлый speech image0.4.0 сохранён как прежний необязательный public release,
не применяется прочим проектам. Предложение перемещения CI-архивов отозвано:
оно не доказывало освобождение нужной Docker filesystem. Общая очистка Docker,
чужих caches/volumes и данные приложений не входят в поставку.
Человеческую приёмку выполняет владелец; исходники, локальные проверки и
проверка реально развёрнутого контура учитываются отдельно.
