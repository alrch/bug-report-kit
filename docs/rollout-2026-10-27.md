Поручение владельца — опубликовать обновлённый общий Kit и обновить все
существующие подключения. Новые установки в ранее не подключённые продукты

## Принятое ограничение голоса

Владелец27октября выбрал голос только для runrunrun. Общий Kit сохраняет
необязательную запись/offline ASR, но v0.4.1 делает текстовый ввод режимом
по умолчанию. Серверный project.voiceEnabled и widget voiceEnabled должны
быть явно true; остальные существующие подключения явно выключают оба флага
и используют лёгкий runtime без Python/model. Диктовка клавиатуры остаётся
обычным текстовым вводом. Сохранённые отчёты/аудио не удаляются.

Релиз v0.4.1 и обновление потребителей готовятся; ниже факты предыдущей

## Проверка и откат

Для серверной замены нужны online SQLite backup, собственная private config copy,
rehearsal на копии, точный прежний image/config и штатный apply. При откате
возвращаются image/config; старую SQLite нельзя записывать поверх новых отчётов.
Синтетические аудио/пользователи используются только в изолированных fixtures;
реальные отчёты не меняют текст, вложения и статус ради проверки.

Публичный неизменяемый SDK/model/image можно переносить между установками;
секреты, SQLite, auth sessions и настройки проектов не переносятся. Старые
архивы и неактивные подключения не считаются живыми потребителями. Долгая
двухминутная запись на слабом1CPU/1GiBконтуре пока отдельно не подтверждена;
короткий synthetic RU ASR прошёл без OOM. Человеческая приёмка остаётся за владельцем.
